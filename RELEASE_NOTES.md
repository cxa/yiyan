## 260801.0

### What’s new

- YiYan can now keep completed learning records, bookmarks, and deletions up
  to date through iCloud, so you can continue learning with the iPhone
  companion while away from your Mac.
- A new iCloud Sync section in Settings lets you turn syncing on, follow its
  progress, or remove your synced learning library when you no longer want
  it in iCloud.
- Commands, file paths, links, and other literal text now stay readable in
  learning notes instead of appearing as internal placeholder labels.

### 本次更新

- 《绎言》现在可以通过 iCloud 同步已完成的学习记录、书签和删除操作，离开
  Mac 后也能在 iPhone 伴侣应用中继续学习。
- 设置中新增了 iCloud 同步区域，可以开启同步、查看同步进度，也可以在不再
  需要时移除保存在 iCloud 中的学习资料。
- 学习笔记中的命令、文件路径、链接和其他原样文本现在会保持清晰可读，不再
  显示为内部占位标记。

## 260729.2

### What’s new

- Very short commands, acknowledgements, and other low-value messages are now
  filtered more reliably, keeping your learning history focused on useful
  writing.
- Days with hundreds of records now open much faster. Recent records appear
  first, and earlier records are added smoothly as you scroll up.
- Loading is clearer: the activity indicator stays in the center, and the
  record count appears only when it is ready.
- Example labels now sit neatly on the same baseline as their sentences.

### 本次更新

- 简短命令、确认语和其他学习价值较低的消息会被更可靠地过滤，让《绎言》的
  学习记录更专注于值得练习的表达。
- 一天内有数百条记录时也能更快打开；最近的记录会先出现，向上滚动时再平滑
  补入更早的内容。
- 加载状态更清晰：进度提示只显示在内容区中央，记录数量会在准备完成后再出现。
- 示例标签现在会与后面的句子整齐地对齐在同一基线上。

## 260729.1

### What’s new

- YiYan now uses far less processor time in the background, even when you have
  a large conversation history, while continuing to notice new messages
  promptly.
- YiYan now handles Claude Code cleaning up a conversation while you work, so
  Settings no longer shows a misleading “no such file” warning and later
  messages continue to be collected normally.

### 本次更新

- 即使已经积累了大量对话记录，《绎言》在后台运行时也会显著减少处理器占用，
  同时继续及时收录新消息。
- Claude Code 在工作过程中清理会话时，《绎言》会安静地继续运行，不再在
  设置中显示误导性的“文件不存在”提示，后续消息也能正常收录。

## 260728.0

### What’s new

- Claude conversations now keep capturing later messages instead of stopping
  after the first one.
- Background task notices, history copied into Codex branch tasks, and other
  system-only messages are skipped, so unrelated or repeated cards do not
  enter your learning history.
- Several new messages no longer start the same work again and again.
  Unfinished items left by an interruption or an older version continue
  automatically when the app opens again.
- When items have been waiting too long, a clear notice lets you restart them
  or remove only the waiting items. Completed learning stays untouched.
- Cards and copied rewrites no longer show formatting marks such as extra
  asterisks or underscores, making them easier to read.

### 本次更新

- 在 Claude 中连续对话时，现在会继续收录后续消息，不再只保留第一条。
- 后台任务通知、Codex 分支任务中复制的历史内容以及其他系统消息会被自动
  跳过，避免无关或重复的卡片进入学习记录。
- 多条新消息同时出现时，不会反复启动同一批处理。意外中断或旧版本留下的
  等待内容，会在重新打开后自动继续。
- 等待时间过长时会出现明确提示，可以重新处理或只移除等待中的内容；已经
  完成的学习记录会保留。
- 卡片和复制出的表达不再显示多余的星号、下划线等格式符号，阅读更清爽。

## 260727.0

### What’s new

This is the first YiYan release.

- Improve the English you write in Pi, Claude Code, and Codex without
  interrupting your work.
- See a natural rewrite and a focused learning note for each useful message.
- Revisit earlier learning by date and bookmark the notes worth keeping.
- Bring YiYan forward from anywhere with a shortcut, or keep it visible while
  you work.
- Record any key combination you prefer for the global show-or-hide shortcut.
- Choose the language used for explanations and the text size that feels most
  comfortable.
- Get started more easily and enjoy a cleaner, more compact reading layout.
- Skip short commands and acknowledgements that do not offer useful learning
  value.
- Receive future versions automatically, with a manual update check available
  in Settings.

Your learning history stays on your Mac.

### 本次更新

这是《绎言》的首个版本。

- 在 Pi、Claude Code 和 Codex 中正常工作时，即可改进自己写下的英文表达。
- 每条有学习价值的消息都会获得更自然的表达和重点明确的学习笔记。
- 可以按日期回顾过往内容，并收藏值得反复复习的笔记。
- 可随时通过快捷键呼出《绎言》，也可以让窗口保持在其他窗口前方。
- 可以录制自己习惯的任意组合键，作为全局显示或隐藏快捷键。
- 可以选择讲解语言和更舒适的文字大小。
- 首次使用更容易上手，阅读布局也更加清爽紧凑。
- 简短命令和没有学习价值的确认语会被自动略过。
- 后续版本可以自动获取，也可以随时在设置中手动检查更新。

学习记录只保留在你的 Mac 上。
